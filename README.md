# Rennrad Manager

Ein Radsport-Teammanager fürs Handy. Führe dein Team durch sechs Saisons, steuere Rennen live über den Rennfunk, jage Gelb, Grün und das Gepunktete Trikot.

**Spielen:** Link im Browser öffnen. Auf dem iPhone in Safari „Teilen → Zum Home-Bildschirm“, unter Android in Chrome „App installieren“. Danach läuft das Spiel auch offline.

Der Spielstand bleibt auf dem eigenen Gerät. Umziehen geht über Einstellungen → Spielstand kopieren/einfügen.
